دوتوپیا

TwoTopia – a number puzzle game for iOS and Android by Flying Acorn

دوتوپیا (TwoTopia) is a free mobile number puzzle game. Shoot number blocks onto the board; blocks with the same number merge into a bigger one. Plan your shots to build long merge chains and climb the leaderboard. The game is designed for Persian speakers.

What you can do in the game

  • Shoot and merge – aim number blocks so equal numbers merge into higher ones.
  • Global leaderboard – compare your best score with other players.
  • Weekly leaderboard – a fresh ranking every week.
